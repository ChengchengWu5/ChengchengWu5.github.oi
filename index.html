Explainable AI (XAI) Project - Cardiovascular Risk Prediction Dashboard

This project demonstrates the development of an Explainable AI (XAI) framework for cardiovascular disease risk prediction using the publicly available health dataset from Kaggle (cardio_train.csv). It compares model performance using multiple evaluation metrics, applies XAI techniques to improve model transparency and interpretability, generates both global and patient-level explanations of model predictions, and builds an interactive dashboard for communicating predictions and explanations to different audiences. The project covers a machine learning workflow, including data cleaning and preparation, feature engineering, model development, performance evaluation, model interpretation, and dashboard building. The aim is not only to predict cardiovascular disease risk but also to provide transparent explanations that help users understand the factors driving each prediction.

Three supervised machine learning algorithms, Logistic Regression, Random Forest, and Gradient Boosting were applied, evaluated using accuracy, precision, recall, F1-Score, and ROC-AUC, and compared based on evaluation results. The Gradient Boosting model achieved the best overall performance and was selected for explainability analysis and dashboard building. To improve transparency and interpretability, SHAP (SHapley Additive exPlanations) was applied to interpret model behaviour at both global and individual levels. For global explanations, plots of Gradient Boosting Model Feature Importance, SHAP Global Feature Importance, and SHAP Summary Beeswarm were produced; for local explanations, patient-level waterfall plot, individual risk factor analysis, and prediction interpretation were provided. The visualisations help users understand how different features contribute to cardiovascular disease risk predictions.

The final output of the project is an interactive dashboard built using Dash and Plotly (app.py). The dashboard allows different audiences, such as patients, clinicians, and machine learning researchers to explore cardiovascular risk disease predictions, investigate model explanations, compare feature importance, and examine patient-specific risk profiles.
